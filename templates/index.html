    Support & Operations Platform

    An internal platform for the company's support and operations teams: secure access, ticket analytics, SAP-to-Snowflake data repair and an in-house AI assistant.

    • Corporate sign-in with Microsoft Entra ID, an extra JWT layer and role-based views, with automated emails when someone is granted access to a section.
    • Transactions that pull tickets from an API into internal databases to monitor and analyse each person's support work, plus a built-in feedback system.
