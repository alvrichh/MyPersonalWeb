# Bug Hunter - Changelog

This changelog tracks game-version changes starting with v1.12.55. Earlier releases are not reconstructed here.

## 1.12.55 - 2026-10-23

### Fixed
- Medusa (World 4) now calls only her dedicated snake enemies instead of also summoning the world's default frogs.
- The existing snake summons remain purple in phase 1 and turquoise in phase 2, with their current timing and limits.

### Scope
- Other bosses' generic backup summons are unchanged.
- No combat balance or Medusa sprite assets were changed.
