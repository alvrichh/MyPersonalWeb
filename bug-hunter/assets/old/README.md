# Retired assets

Pictures replaced in the game, kept for reference or to roll back. Nothing in the game loads them (they are still
published, under `/images/game/old/...`, like any asset). Each folder mirrors where the files used to live.

- `02-hotfix-inferno/enemies/demon-{bug,ticket,legacy}-0..3.webp`, `demon-bug-icon.webp`: the fire world's first
  four-frame imp, skull and gargoyle, replaced in 1.13.42.
- `01-backlog/bosses/monolith-0..8.webp`: the Backlog's first Monolith, cut from a small sheet (bodies about 90 px
  tall), replaced in 1.13.43.
- `06-the-arena/enemies/greek-legacy-0..3.webp`: the Arena's first four-frame shield wall, replaced in 1.13.44.
- `01-backlog/bosses/kernel-0..8.webp`: the Backlog's first Kernel Panic (bodies about 120 px), replaced in 1.13.45.
- `shared/hero/{intern,kratos,medusa}-base-*.webp`: the intern, Kratos and Medusa skins before 1.14.26 (Kratos and
  Medusa recut from their sheets, the intern cleaned up; grey haze, Medusa's lime/yellow key fringe, specks).
- `shared/hero/reaper-base-*.webp`: the first Server Reaper skin, replaced by the owner's redrawn sheet in 1.14.38.
- `shared/hero/reaper-v2/reaper-base-*.webp`: the redrawn Server Reaper as first cut (scythe counted in its height, so the figure was smaller than alvrich), replaced in 1.14.44.
- `special/siege/units/ally-swordsman-{2,4,5}-*.webp`: the swordsman's forms with their red scarf and capes as drawn; recoloured blue in 1.14.60.
- `special/siege/reserve/{armed-fighter-1-4,archer-1-4-wizard-1-3,mech-1-6,gunner-blaster-1-4}.webp`: the owner's second set of
  sheets for the allied troops, kept in reserve and not used by the game (one row per level, six poses each, on white). The ninja
  master (archer 4) there is the owner's preferred one; the game uses the first set (1.15.56).
- `special/siege/units-wizard-purple/ally-wizard-{1,2}-*.webp`: the wizard's levels 1 and 2 with their purple hat and robe, recoloured light and dark blue in 1.15.64.
- `special/siege/units-heavy-robot/ally-heavy-robot-{1..4}-*.webp`: the heavy robot's four forms before the owner's redraw (1.15.65).
- `special/siege/units-gunner-blue/ally-gunner-{2,3}-*.webp`: the gunner's levels 2 and 3 with their gold ornaments, recoloured silver-blue and red in 1.15.67.
