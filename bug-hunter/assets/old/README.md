# Retired assets

Pictures replaced in the game, kept for reference or to roll back. Nothing in the game loads them (they are still
published, under `/images/game/old/...`, like any asset). Each folder mirrors where the files used to live.

- `02-hotfix-inferno/enemies/demon-{bug,ticket,legacy}-0..3.webp`, `demon-bug-icon.webp`: the fire world's first
  four-frame imp, skull and gargoyle, replaced in 1.13.42.
- `01-backlog/bosses/monolith-0..8.webp`: the Backlog's first Monolith, cut from a small sheet (bodies about 90 px
  tall), replaced in 1.13.43.
- `06-the-arena/enemies/greek-legacy-0..3.webp`: the Arena's first four-frame shield wall, replaced in 1.13.44.
- `01-backlog/bosses/kernel-0..8.webp`: the Backlog's first Kernel Panic (bodies about 120 px), replaced in 1.13.45.
- `shared/hero/{intern,kratos,medusa}-base-*.webp`: the intern, Kratos and Medusa skins before their cleanup in
  1.14.26 (grey backdrop haze, Medusa's lime/yellow key fringe, specks and small holes).
